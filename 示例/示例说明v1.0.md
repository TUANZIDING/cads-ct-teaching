# 示例说明 v1.0 · Examples

| 文件 | 作用 |
| --- | --- |
| `运行CADS示例v1.0.sh` | 官方 README 中的安装与推理命令（教学示范；请按自己的 GPU/CUDA 修改 PyTorch 安装行） |
| `L3面积示例v1.0.py` | 在 L3 椎体中层计算掩膜面积（cm²）与平均 HU，演示“掩膜 → 面积”的计算 |

## 用开放数据跑 L3 示例 · Run the L3 example on open data

1. 从 TotalSegmentator 数据集 v2.0.1（Zenodo，doi:10.5281/zenodo.10047292，CC BY 4.0）取病例 `s0423` 的 `ct.nii.gz` 与 `segmentations/`。
2. 运行：

```sh
python3 示例/L3面积示例v1.0.py s0423/ct.nii.gz s0423/segmentations/vertebrae_L3.nii.gz \
  s0423/segmentations/iliopsoas_left.nii.gz s0423/segmentations/iliopsoas_right.nii.gz \
  s0423/segmentations/autochthon_left.nii.gz s0423/segmentations/autochthon_right.nii.gz
```

本仓库作者在 2026-11-13 的运行结果（参考掩膜，L3 中层 z=190）：髂腰肌 左 10.1 / 右 6.3 cm²，背深肌（autochthon）左 28.4 / 右 29.7 cm²。

> 仅供教学：这不是完整的骨骼肌面积（SMA），也没有做 HU 阈值处理；临床或科研使用需按已发表方法（如 Mourtzakis 2008，doi:10.1139/H08-075）建立并验证流程。
